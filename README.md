# Planner

A phone-first personal planner designed to be hosted with GitHub Pages.

## Upload to GitHub

Upload every file and folder in this package to the top level of the repository. The repository should show:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `README.md`
- `assets/`
- `css/`
- `js/`

Do not upload the ZIP itself. Do not move everything into an extra folder.

## Turn on GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Click **Save**.

## Storage

Schedules, check-offs, streaks, and history remain in the browser's local storage. They are not committed to GitHub.
